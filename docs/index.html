开始使用

先体验，再连接你的账号。

安装包包含所有程序文件。解压到可写入的文件夹后，打开 TG-Harbor.exe。

  1. 1

    体验本地演示

    首次启动会展示原创示例频道。选择媒体并下载，确认文件已经保存到本地。

  2. 2

    申请自己的 API 参数

    到 my.telegram.org/apps 创建 Desktop 应用，获取 API ID 与 API Hash。申请表的 URL 可填写发布后的本项目主页或源码仓库地址。

  3. 3

    在星港中授权登录

    进入“设置与连接”，填写 API 参数和需要的 SOCKS5 代理。用手机 Telegram 扫码授权；如有两步验证，在本地程序中输入密码。

  4. 4

    选择内容，开始归档

    浏览有访问权限的对话，选择媒体，或添加消息链接。批量任务可按类型、关键词、日期和文件大小筛选。

使用前了解

常见问题

登录信息会上传到这个网站吗？

这个主页只提供介绍、使用说明和公开文件下载，不接收 Telegram 凭据。API 参数和扫码登录都在 Windows 程序中完成。API Hash 使用 Windows DPAPI 加密保存；Telegram 会话以 Telethon 的标准格式保存在程序的数据目录。

能下载所有频道的内容吗？

需要当前账号拥有访问权限，并受 Telegram 的服务器规则与限流约束。软件不会自动加入频道，也不保证下载服务器不允许获取的内容。

自动归档什么时候运行？

软件运行、账号已连接且对应规则已开启时，自动处理规则开启后的新媒体。历史内容通过批量任务扫描。当前版本使用串行下载队列。

这个版本做过哪些验证？

1.0 版已通过 14 项测试，覆盖实际文件保存、断点续传、去重、任务恢复和本地接口访问控制；界面操作保存的 5 个示例文件通过原文件哈希比对。未使用真实账号完成在线下载测试，在线功能需使用者自行登录验证。

星港与 TG-FF、Telegram 是什么关系？

星港是参考 TG-FF 公开资源管理流程独立实现的项目，不是 TG-FF 或 Telegram 的官方产品。当前版本侧重浏览、下载与归档，未包含批量发送、DOCX 导出、Stream 建站及多账号系统。
